# PixelForge brand asset index

Small text manifest for the shared brand folder. Binary packs live on the
design NAS and are not mirrored to PixelDrop.

| asset              | format | notes                          |
| ------------------ | ------ | ------------------------------ |
| logo-primary       | svg    | blue mark, 24px clear space    |
| logo-mono          | svg    | single colour, print only      |
| palette            | json   | `pixel-art-pack.json`          |
| type-specimen      | pdf    | Inter, 4 weights               |
| social-templates   | fig    | one file per platform          |

Do not rename the `logo-primary` file: the press kit links to it directly.
