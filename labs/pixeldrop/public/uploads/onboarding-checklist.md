# PixelDrop onboarding checklist

For new studio members on the local demo instance.

- [ ] Open the Files page and download `welcome.txt`
- [ ] Sign in with the demo account shown on the sign-in page
- [ ] Check the "Your private drops" section for your own files
- [ ] Submit the upload metadata form with a test name
- [ ] Read `robots.txt` if you plan to wire up a crawler
- [ ] Sign out before handing the machine to the next person

Notes
-----
- Uploads are metadata only: name, visibility and a short description.
- Private drops are listed per owner. The prototype does not enforce the
  per-file ACL yet; that ships in Q4 (see `roadmap-q4.txt`).
- Reset is just a restart: sessions and pending uploads live in memory.
